# Clinical Data Processing & Automation Suite (SDTM / ADaM)

A daily-updated portfolio of automated macros, scripts, and pipelines for transforming raw clinical trial data into CDISC-compliant SDTM and ADaM datasets.

## Repository Structure
- `macros/`: Reusable transformation routines
- `raw_data/`: Sample raw clinical input files
- `sdtm_output/`: Study Data Tabulation Model outputs
- `adam_output/`: Analysis Data Model outputs
- `specs/`: Data mapping specifications and controlled terminologies
- `tests/`: Automated validation checks
